# DA-project
This project focuses on analyzing sales data from a Diwali festival campaign to uncover customer purchasing behavior, sales performance, and market trends. The insights derived can help businesses make informed decisions for future festive season strategies.
The dataset contains transactional sales data, including customer demographics and purchase information.

Key Columns:

User_ID

Gender

Age

Occupation

City_Category

Marital_Status

Product_ID

Product_Category

Purchase

🎯 Objectives
Clean and preprocess the dataset

Explore data using visualizations

Understand customer demographics

Identify top-selling product categories

Analyze purchase patterns by gender, age, and city

Provide actionable insights for marketing and inventory
